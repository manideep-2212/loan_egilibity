# Explainable and Fair AI for Loan Eligibility Decision-Making

## Project Overview
This project applies data mining and machine learning techniques to analyze loan approval data and predict loan eligibility.

The system explores patterns in financial attributes such as applicant income, credit history, and loan amount to identify factors influencing loan approval decisions.

## Models Used
- Logistic Regression
- Decision Tree

## Data Mining Concepts Used
- Data preprocessing
- Exploratory Data Analysis
- Classification
- Feature importance analysis
- Model evaluation
